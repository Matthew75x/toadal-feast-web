# Toadal walk cycle v1

An eight-frame transparent walk-in-place animation for the golden frog prince, based on the user-supplied character reference.

- toadal-walk-cycle.webp — lossless animated WebP, 10 fps, infinite loop, alpha transparency.
- toadal-walk-cycle-spritesheet.png — original 4×2 frame sheet.
- frames/frame-01.png through frame-08.png — individual 444×444 transparent frames in playback order.
- preview.html — local preview page.

The sprite sheet and frame poses were created with OpenAI image generation from the supplied reference image. The walk direction faces slightly toward camera; the backpack stays on image-left. Frame order is left-to-right across the top row, then left-to-right across the bottom row.

For share-link cards, use a static frame or poster for Open Graph metadata because many social apps show only a still preview. The animated WebP can be used on the landing page and in clients that support animated WebP.
