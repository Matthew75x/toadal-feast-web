# BETA-01 — Website Beta Navigation / Content Minimum

**Status:** PLANNED

## Goal

Supply the smallest coherent non-game website surface required around the qualified Play experience.

## Required route families

- Home
- Play
- World hub
- Characters hub
- Toadal profile
- App / Get the Game
- Support
- Legal / Privacy
- 404/recovery

Wicked Bites and Arcade player routes are handled by Play/Arcade work.

## Content rules

- only canonical/approved character and world facts;
- no invented lore to fill gaps;
- generated mockup copy is not canon;
- app/store claims must match verified availability;
- future Account/Community/Store functions must remain visibly future/coming-soon;
- no account requirement for the beta Play experience;
- no global leaderboard claims.

## Design rules

- preserve accepted Home visual direction;
- reuse existing shell/components;
- no second site redesign;
- core routes must feel intentional, not placeholder scaffolds;
- phone/tablet/desktop first-class.

## Evidence

- content/reference validation;
- canonical asset audit;
- responsive screenshots;
- keyboard/focus smoke;
- broken links;
- metadata;
- 404 recovery;
- static export/base-path.

## Stop

Do not use this work order to start Stories, Feast Pass, backend accounts, commerce, or mass editorial expansion.
