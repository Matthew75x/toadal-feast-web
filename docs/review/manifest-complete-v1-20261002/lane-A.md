## Audit result

The baseline has 30 Studio page records, but those records do not cover 30 distinct manifest families. Three family routes are absent (Article/Devlog, Leaderboards, Roadmap); three extra game-detail routes make the route count appear complete. The News Article, Leaderboards, and Roadmap page families therefore remain buildable omissions.

One additional source-integrity blocker is confirmed: `studio-project/toadal-feast-website/pages/app.json` is invalid JSON. Parsing stops at line 26, where an extra `}` closes the `components` array. The App page's Infinite mode content is after this syntax error; TOADAL Studio cannot safely consume the page source as written. All other files in `pages/*.json` parsed in the same read-only check.

Other high-impact buildable gaps are the missing website leaderboard view/adapter; no connected Treat catalog or functional link from the Home candy discoveries into the Pass Treat count; and no claimable reward catalog. Stories/Manga/Reader templates and publishing behavior exist, but the published content registry contains zero series, chapters, and pages. Media and News remain truthful but sparse empty previews.

**Shared-checkout snapshot after other lanes began:** the App JSON parse error still reproduces. A new untracked `pages/leaderboards.json` has appeared, but `pages/index.json` still has 30 entries and no Leaderboards route at this snapshot, so the file is not yet a registered manifest surface. This is an in-progress integration observation, not a claim that the lane's ongoing work is finished.
