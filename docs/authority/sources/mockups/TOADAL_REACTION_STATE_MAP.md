# TOADAL Reaction State Map

| Route/context | Toadal state |
|---|---|
| World / roadmap / discovery | map guide / pointing |
| Media / news / devlog | creator or writing state |
| Feast Pass quest | adventure guide |
| Reward earned / collection | treasure celebration |
| Leaderboard / high score | trophy/victory |
| App conversion | smartphone/download |
| Account / signup | registration form |
| Search | magnifier/detective |
| Community | social/open arms |
| Store | merch |
| Support | headset/tablet |
| Contact/feedback | clipboard/mail |
| Privacy | shield/padlock |
| Construction | hard hat/tools |
| Settings/sound | gear/bell/mute variants |
| Error/404 | explorer/map reaction |

Keyboard focus and touch equivalents should trigger the same semantic reactions as mouse hover. Reduced motion retains state changes without movement.
