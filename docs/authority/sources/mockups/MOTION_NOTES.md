# Motion Notes

Motion has jobs: feedback, reveal, continuity, character personality and ambience.

- Companion: short pose transition or subtle entrance when route/context changes; reduced motion keeps pose/state changes but removes animation.
- Cards: small lift/glow on hover/focus; no constant floating.
- Progress/reward events: brief gold-to-pink fill and reward sparkle, then settle.
- Environment: restrained layered parallax only on large scenic heroes; disable under reduced motion.
- Page transitions: shared navigation remains stable; content fades/slides minimally.
- Hidden Treat: concise collection burst and contextual Toadal reaction.
