# Responsive / Mobile Plan

Representative 390×844 mockups are included for Home, Play, World, Stories, Feast Pass, App, Account, Community, Search and Support.

Mobile principles:
- recompose to one primary column; do not shrink desktop grids;
- preserve fast Play access and bottom navigation;
- keep hero copy readable over art;
- keep the reactive Toadal companion present but smaller and non-blocking;
- reduce ornamental motion under reduced-motion preferences while retaining semantic state changes;
- move secondary navigation into More/drawer patterns;
- keep Guest / Coming Soon / Preview states explicit.
