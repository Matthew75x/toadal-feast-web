# TOADAL FEAST Website — Definitive Mockup Package

This package was produced from `TOADAL_WEBSITE_CODEX_HANDOFF_LEAN_2026-09-29.zip`.

## What is authoritative vs newly produced
- Pages 1–10: the handoff's approved Batch 1 visual-direction images are preserved unchanged as the official desktop mockups.
- Pages 11, 14 and 18: the handoff's supplied additional concept references are preserved as desktop concept-reference screens.
- Pages 21 and 22 were rebuilt from their concept direction so Community/Store truthfully mark unavailable connected/commerce features as preview or coming soon.
- The remaining desktop pages are newly composed HTML/CSS mockups derived from the same visual system and real authoritative Toadal functional assets.
- No production site was modified.

## Preview
Double-click `LAUNCH_MOCKUPS.bat` on Windows. It starts a local server and opens the gallery at `http://localhost:8765/`.

## Structure
- `desktop/` — 30 desktop mockup PNGs.
- `mobile/` — representative 390px mobile journey screenshots.
- `prototype/` — clickable page mockups and gallery.
- `assets/` — only the assets/crops needed by the prototype.
- `PAGE_MANIFEST.md`, `DESIGN_SYSTEM.md`, `MOTION_NOTES.md`, `IMPLEMENTATION_NOTES.md`, `ASSET_MAP.md`, `TOADAL_REACTION_STATE_MAP.md`, `FEATURE_SALVAGE_LEDGER.md`, `QA_REPORT.md`.
