# Design System

Derived from the handoff visual authority.

## Identity
- TOADAL FEAST is foreground brand/world; TOADAL GAMES stays subordinate except About/business contexts.
- Canonical Toadal: golden-yellow, small crown, red scarf, explorer/adventurer identity.

## Core visual tokens
- Chocolate navigation: `#3A1A12` / `#5B2A1B`.
- Warm cream surfaces: `#FFF7DF` / `#FFF1C7`.
- Primary Feast pink: `#FF2F7D`.
- Reward/crown gold: `#F6B91D`.
- Deep heading ink: `#321547`.

## Components
Cream cards with gold borders and soft shadows; pink pill CTAs; gold/cream secondary buttons; compact status tags; adventure-style progress bars; contextual Toadal companion in the lower-right support rail.

## Layout
Desktop screens target 1672×941 to match supplied authority images. Main generated pages use a hero band, dense organized main content, 320px support rail and persistent footer. Mobile recomposes to a single column rather than scaling the desktop grid.
