## 8. Anti-waste rule

Before adding any new image file:

1. search `assets/index.json`,
2. search current website reference assets,
3. search canonical TOADAL game assets if the usage is a real product claim,
4. verify whether a truthful empty/future state is preferable,
5. only then add a new asset.

The final site should look richer primarily by composing the substantial asset library already present, not by creating unrelated new artwork.
