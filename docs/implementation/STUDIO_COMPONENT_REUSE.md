# WO-001 — Studio-native component reuse

- Date: 2026-09-30
- Studio: 1.4.2

This maps the requested shell/component family to real Studio 1.4.2 constructs. The source gate verifies component types, symbol references, behavior/markup, and generated shell output; it does not count display names alone.

| Requested concept | Studio-native representation and evidence |
|---|---|
| `SiteHeader` | Generated by the `generic-site` renderer from `collections/site.json` and `collections/navigation.json`; emitted on Home and 404. |
| `SiteFooter` | Generated global generic-site footer from the same site/navigation collections; emitted on Home and 404. |
| `RouteShell` | Renderer-owned `header` / `main#main-content` / `footer` wrapper shared by every generic-site route. |
| `PrimaryButton` | Synchronized `core.button` symbol; used by the 404 recovery component. |
| `SecondaryButton` | Synchronized `core.button` symbol; used by four 404 recovery actions. |
| `CreamPanel` | Synchronized `core.content-section` symbol with a styled `cream-panel` variant; used by the 404 recovery surface and exposed as a section pattern. |
| `DarkFeaturePanel` | Synchronized `core.rich-text` symbol used by the Home Feast Pass planned/preview summary; exposed as a section pattern. |
| `SectionHeading` | Synchronized `core.text` h2 symbol exposed through the `SectionHeading` section pattern. |
| `StatusChip` | Synchronized `core.badges` symbol exposed through the `StatusChip` section pattern. Studio 1.4.2's closest native built-in is a badges group, so the pattern supplies a single status item. |
| `CategoryTabs` | Synchronized rich-text symbol used for the Home preview filters; its real `data-game-tab` markup is enhanced by the existing Home filter behavior and the pattern makes it insertable on a later route. |
| `ToadalCompanion` | Synchronized rich-text symbol used by Home and exposed through a section pattern; existing `advanced-code` behavior provides contextual copy, focus/pointer response, and local minimize preference. |

`SearchField` is preserved as the existing accessible, disabled Home search form, rather than using `core.site-search`, whose built-in behavior would imply that search is active. Search remains honestly unavailable.

Studio 1.4.2 symbols merge a component's saved props with instance props but do not declare typed slots or parameter schemas. The native pattern library inserts copies rather than live synchronized instances. Accordingly, synchronized symbols are used for repeated structures, native section patterns for simple heading/status/panel templates, and the generated global renderer for the site shell. Home's custom search/filter/companion behavior remains in its real rich-text markup plus the existing project-level advanced code; no fake metadata-only components or renderer patches were added.
