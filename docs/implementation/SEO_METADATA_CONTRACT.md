# TOADAL FEAST — SEO / Metadata Contract

## Every public static page
Must define:
- unique `<title>`
- meta description
- canonical URL generated from deployment base/origin config
- Open Graph title/description/image when a real approved share image exists
- viewport
- theme color
- robots state

## Staging
GitHub Pages staging remains:
`noindex, nofollow`

Do not accidentally flip staging to indexable during feature work.

## Production
Indexing is a release decision, not a component default.

## Dynamic content
News, stories, characters, games and media derive metadata from structured content.
No fabricated dates, review counts, ratings or author identities.

## Structured data
Only emit schema.org data when the underlying content is real and fields are factual.

## Share images
Use approved real key art / derivatives.
Generated mockup product screenshots are not share evidence for the app/game.
