# TOADAL FEAST — Public Truth Rules

Every feature resolves to one state:
PUBLIC / PREVIEW / PLANNED / COMING_SOON / DISABLED.

Never present as live:
- Store checkout before commerce exists
- global/friends leaderboards before persistent validated service exists
- community posting/social graph before backend/moderation exists
- account sync before authentication + migration exists
- app or browser-game screenshots that are AI-fabricated
- unapproved release dates
- generated roadmap items as approved commitments
- conceptual merchandise as inventory

A future interface may be shown only when:
1. its state is clearly visible;
2. its CTA cannot mislead users into thinking the backend works;
3. copy explains what exists now;
4. useful live alternatives are offered.

Mockup scores, dates, rewards, quest values and roadmap items are illustrative unless separately approved.
