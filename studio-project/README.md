# TOADAL Studio Project

This folder is reserved for the clean TOADAL FEAST website Studio project.

Do not copy the legacy `projects/toadal-games` Studio project here.
Create a fresh independent site project with TOADAL Studio 1.4.1.

The Studio MCP process must set `TOADAL_PROJECT` explicitly to this project's `project.json`.

Generated static output belongs in the repository-level `dist/` directory.
